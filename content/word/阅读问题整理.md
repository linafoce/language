| :-- | :-- | :-- |
| 〜ていれば | 会社で働いていれば | 如果…… |
| 〜ことがある | 部下に仕事を教える立場になることがある | 有时会…… |
| 〜ずに | 社内用語や専門用語を使わずに | 不……而…… |
| 〜ようにしている | 説明するようにしている | 尽量做到…… |
| 〜からだ | 大きな差があるからだ | 因为…… |
| 〜と思って | いずれ覚えなければならないからと思って | 以为……，想着…… |
| 〜と | 難しい言葉を使って説明すると | 一……就…… |
| 〜という印象を与える | 仕事自体が難しいという印象を与える | 给人……的印象 |
| 〜ようという | 理解しようという意欲 | 想要……的 |
| 〜のではないだろうか | 教え方をすることではないだろうか | 不就是……吗；委婉判断 |
| 〜にとって | 部下にとって分かりやすい言葉で | 对……来说 |
| 〜ようとする | 一気に教え込もうとする | 试图…… |
| 〜てもらう | 仕事を正確に覚えてもらうには | 让对方…… |
| 〜ことが大切だ | 考えて教えることが大切だ | ……很重要 |
| 〜ようとしないで | 一度に教えようとしないで | 不要试图…… |
| 〜に絞って | 担当してもらう仕事に絞って | 限定在…… |
| 〜ば | 内容を限定すれば | 如果…… |
| 〜たり〜たりする | 説明したり、やらせてみたりして | 列举动作 |
| 〜に合わせて | 部下のレベルに合わせた内容やスピードで | 配合……，按照…… |

### 可直接记的句子

| 表达 | 中文 |
| :-- | :-- |
| 誰が聞いてもわかる言葉で説明する | 用谁听了都能懂的话说明 |
| 教える側と教えられる側の知識や経験には大きな差がある | 教的一方和被教的一方在知识经验上有很大差距 |
| 仕事自体が難しいという印象を与える | 给人“工作本身很难”的印象 |
| 理解しようという意欲を失ってしまう | 失去想要理解的积极性 |
| 部下の能力に応じた教え方をする | 根据部下能力来教 |
| 部下にとって分かりやすい言葉で仕事を理解させる | 用对部下来说易懂的话让其理解工作 |
| 多くの仕事を一気に教え込もうとする | 想一口气灌进去很多工作 |
| 仕事を覚える側の負担を考える | 考虑学习工作一方的负担 |
| 担当してもらう仕事に絞って教える | 限定在要其负责的工作上来教 |
| 部下のレベルに合わせた内容やスピードで教える | 按照部下的水平调整内容和速度来教 |
| 確実に仕事を覚えてもらうための近道 | 让对方切实掌握工作的捷径 |
