# 授受动词总结

## 1. 基础四剑客：搞清“谁给谁”

**核心口诀：** 看**主语**是谁，看**方向**哪边。

| 动词      | 核心含义                 | 方向 (→)                | 助词                        | 注意                  |
| :------ | :------------------- | :-------------------- | :------------------------ | :------------------ |
| **あげる** | **给** (我给别人 / 别人给别人) | 我 → 他人<br>他人 A → 他人 B | **に** (给对象)               | ⚠️ **绝对不能**用于“别人给我” |
| **もらう** | **得到/领受**            | 我 ← 他人<br>他人 A ← 他人 B | **に / から** (从对象)          | 主语是“接受者”            |
| **くれる** | **给** (别人给我)         | 他人 → **我** (或我的家人)    | **が** (给的人)<br>**に** (给我) | **主语必定是别人**         |
| **やる**  | **给** (给下位者)         | 上 → 下 (动植物/晚辈)        | **に** (给对象)               | 现在的日语中，对人用`あげる`更礼貌  |

---

## 2. 敬语升级版：看人下菜碟

当涉及到长辈或上级时，必须换用敬语词汇。

| 原形      | ⬆️ 尊他 (别人给我)    | ⬇️ 自谦 (我给别人 / 我领受) |
| :------ | :-------------- | :----------------- |
| **くれる** | **くださる** (老师给我) | (无)                |
| **あげる** | (无)             | **さしあげる** (我呈送给老师) |
| **もらう** | (无)             | **いただく** (我从老师那领受) |
| **やる**  | (无)             | (通常不用，直接用さしあげる)    |

---

## 3. 两种用法：给东西 vs 给动作

* **物品授受**：`N を あげる / くれる / もらう` (给我书 / 得到书)
* **动作授受**：`Vて + あげる / くれる / もらう` (为我做... / 我请人做...)
  * *例：荷物を持って**あげる**。 (我帮你拿行李。)*

---

## 4. 高阶难点：使役 + 授受 (`(さ)せて` 系列)

这是考试中最容易晕的部分，核心逻辑是**“让 / 允许”**。

| 句型                                    | 直译逻辑                         | **真实含义 (人话)**             | 常用场景                      |
| :------------------------------------ | :--------------------------- | :------------------------ | :------------------------ |
| **V(さ)せて もらう**<br>V(さ)せて いただく | 让我做 + 我领受恩惠<br>(我得到做某事的机会)   | **请允许我做……**<br>**我得以做……** | 极其常用的自谦语。<br>*"请允许我自我介绍"* |
| **V(さ)せて くれる**<br>    V(さ)せて くださる     | 让我做 + 别人给我<br>(别人给我“让我做”的恩惠) | **(别人) 让我做……**            | 强调别人的好意。<br>*"老师让我休息"*    |
| **V(さ)せて ください**                       | 让 + 我做 + 请                   | **请让我做……**                | 直接的请求。                    |

---

## 5. 易错点：借 (Lend) vs 借 (Borrow)

记住图片中的口诀：**“贷出借进”**。

* **貸（か）す** = **贷**出 (Lend) → 我借给别人 (`貸してあげる`)
* **借（か）りる** = **借**进 (Borrow) → 我找别人借 (`借りてしまう`)

---

## 6. 做题秘籍

考试遇到授受动词，按这三步走：

1. **圈三要素**：圈出 **主语 (は/が)**、**对象 (に)**、**动词**。
2. **定方向**：
   * 看到 `私に` (给我) → 必选 `くれる / くださる`。
   * 看到 `私は` (我...) → 排除 `くれる` (除非是“我收到了” `もらう`)。
3. **看身份**：
   * 对方是老师/上级 → 必选敬语 (`いただく / くださる / さしあげる`)。

**避坑指南：**

* **不要恩将仇报**：如果事情给别人带来麻烦，不能用授受动词。
  * *× 别人**为我**踩了脚 (足を踏んでくれた)* → 这种时候只能用被动态 `踏まれた`。
* **身体/所属物**：涉及身体部位时，助词要注意。
  * *〇 私**の**荷物を持ってくれた。 (帮我拿了行李)*
