# て形补助动词

## 1. Vている（ておる / てる）

**接续：**

* **助词 を ＋ 他动词て形 ＋ いる**
* **助词 が ＋ 自动词て形 ＋ いる**

**核心用法：**

1. **正在进行**
   * 小野さんは今本を読んでいます。
   * 雨が降っています。
2. **结果状态的存续**
   * 私は車を持っている。
   * 王さんのことを知っていますか。
3. **反复性、习惯性的动作**：常搭配「いつも・よく・毎日」。
   * 洋子さんはアルバイトをしながら学校に通っています。
   * そのお母さんは娘に毎日牛乳を飲ませています。
4. **身份、职业**：`身份・职业 ＋ を ＋ している`
   * 李さんは高校の学生をしている。
   * 私は高校の教師をしています。
5. **描述外貌、性质、颜色**：`名詞 ＋ を ＋ している`
   * 彼女は可愛い顔をしている。
   * 私は1987年に生まれている。
6. **经历、经验**
   * 私は3年前にも同じ病気をしている。
   * 王さんは大学時代日本に留学している。

---

## 2. Vてある

**接续：**

* **助词 が ＋ 他动词て形 ＋ ある**

**核心用法：**

1. **表示人为作用下的结果状态存续**
   * 壁にいろいろなポスターが貼ってある。
   * ドアが開けてあります。
2. **表示事先已经把某事做好了**
   * そのことは山田さんに伝えてあります。
   * 試験に必要なことは全部教えてあります。

> **注意：** 描述当下的结果状态时一般不用过去式。只有在描述过去某个具体时间点的人为结果状态存续时，才使用过去式。
>
> **昨日、その部屋に入ったら、窓が開けてあった。**

---

## 3. Vておく（とく）

**接续：**

* **動詞て形 ＋ おく**

**核心用法：**

1. **事先去做**：`Vておきます / Vておく`
   * お客さんが来る前に、部屋を掃除しておきます。
   * 山田さんに来るかどうか聞いておいてください。
2. **事先做好 / 保持原状**：`Vておきました / Vておいた`
   * そろそろ暗くなるから、電気をつけておきました。
   * お客さんが来ないから、コップを元の場所に戻しておいた。

### 辨析：ている / てある / ておく

| 词形 | 核心含义 | 备注 |
| :--- | :--- | :--- |
| **ている** | ① 正在进行<br>② 结果状态的存续<br>③ 习惯 / 身份 / 外貌 / 经历 | 侧重对现象状态的描述 |
| **てある** | ① 人为作用下的结果状态存续<br>② 事先已经做好了某事 | 侧重人为完成后留下的状态 |
| **ておく** | ① 事先去做某事<br>② 事先做好某事 / 保持原状 | 侧重准备动作 |

---

## 4. Vてみる（見る）

**用法：** 表示尝试做某事。

* もう一度先生と相談してみます。
* 似合うかどうか、着てみてください。

> **补充：Vてみせる（見せる）**
>
> 表示做某事的决心，有“做给……看”的语感。
>
> * 今年どうしても試験にパスしてみせる。
> * 今度の試合、絶対勝ってみせる。

---

## 5. Vてしまう（仕舞う / ちゃう）

1. **单纯表示动作的结束、完成**
   * この本をもう全部読んでしまいました。
   * 開けちゃおう。
2. **表示动作结束后伴随的消极、遗憾语气**
   * 大切な資料を忘れてしまいました。
   * 彼に騙されてしまって困っています。

> **补充：**
>
> 与情感类词语，如「泣く・笑う・感動する」等搭配使用时，`てしまう` 可以表示该情感难以抑制，自然流露出来。

---

## 6. Vていく / Vてくる

### ていく（行く）

1. **表示以说话人为起点，动作由近及远**
   * 鳥が山の方へ飛んでいきました。
   * 李さんはあちらへ歩いていきます。
2. **表示从现在到将来的发展变化过程及趋势**
   * これから寒くなっていきます。
   * 田舎の人口はだんだん減っていくでしょう。
3. **表示原来存在的事物消失不见**
   * だんだん雪が溶けていきます。
   * 毎日、多くの人が交通事故で死んでいきます。
4. **表示在某地做完某事之后，再到别的地方去**
   * 日本に行く前に、日本語を勉強していきます。
   * 病院へ行く途中で、お見舞いの花を買っていきましょう。

### てくる（来る）

1. **表示以说话人为起点，动作由远及近**
   * 李さんは私に向かって走ってきました。
   * 遠くから音楽が伝わってきました。
2. **表示由过去到现在某种状态的变化过程和趋势**
   * 私は子供の時から日本語を勉強してきました。
   * 最近、日本に留学する人が増えてきました。
3. **表示某种状态开始或出现**
   * 雪が降ってきました。
   * ずっと読んでいたので、目が疲れてきました。
4. **表示循环性动作，即“去了又来”**
   * ちょっと手紙を出してきます。
   * タバコを買いに行ってきます。

### 辨析：ていく / てくる

| 比较项目 | ていく（行く / てく） | てくる（来る） |
| :--- | :--- | :--- |
| **距离感** | 由近及远 | 由远及近 |
| **距离感延伸** | 消失 | 出现 |
| **时间段** | 现在到未来 | 过去到现在 |
| **动作顺序** | 做完再去 | 去了又来 |

## 7. 还原练习与做题方法

### 还原练习答案

| 变形 | 原形 | 语法 / 备注 |
| :--- | :--- | :--- |
| **ています** | **ている** | `Vている` 的 `ます` 形，表示正在进行或状态存续。 |
| **ていきます** | **ていく** | `Vていく` 的 `ます` 形，表示由近及远、消失或将来。 |
| **ておって** | **ておる** | `Vておる` 的 `て` 形。`ておる` 是 `ている` 的自谦语或郑重语。 |
| **ておいて** | **ておく** | `Vておく` 的 `て` 形，表示事先准备或放任不管。 |
| **ております** | **ておる** | `Vておる` 的 `ます` 形。`ている` 的自谦语，如「私は〜を知っております」。 |
| **ておきます** | **ておく** | `Vておく` 的 `ます` 形。 |
| **ていって** | **ていく** | `Vていく` 的 `て` 形。注意：「行く」的て形是促音变「行って」。 |
| **ていて** | **ている** | `Vている` 的 `て` 形，也就是 `て＋いる` 中「いる」变为「いて」。 |
| **てこない** | **てくる** | `Vてくる` 的 `ない` 形。`くる` 变为 `こない`。 |
| **てきて** | **てくる** | `Vてくる` 的 `て` 形。`くる` 变为 `きて`。 |
| **といて** | **ておく** | 口语缩略形式。`ておいて` 变为 `といて`。 |
| **ちゃった** | **てしまう** | 口语缩略形式。`てしまった` 变为 `ちゃった`，表示遗憾或彻底完成。 |

### 做题方法

1. **看题目里的助词和接续**：特别注意 `ている` 和 `てある` 的区别。
2. **注意还原和用法**：先判断是哪个补助动词。
3. **用方向判断 `ていく / てくる`**：通过时间方向、空间方向判断。
