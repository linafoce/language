# 4、て形补助动词

## (一) Vている (ておる) (てる)

*   **接续：**
    *   (助词を) + 他动词 + 「ている」
    *   (助词が) + 自动词 + 「ている」

1.  **正在进行**
    *   小野さんは今本を読んでいます。
    *   雨が降っています。
2.  **结果状态的存续**
    *   私は車を持っている。
    *   王さんのことを知っていますか。
3.  **反复性、习惯性的动作** (常搭配 “いつも・よく・每日”)
    *   洋子さんはアルバイトをしながら学校に通っています。
    *   そのお母さんは娘に每日牛乳を飲ませています。
4.  **身份、职业**：「身份、职业 + を + している」
    *   李さんは高校の学生をしている。
    *   私は高校の教師をしています。
5.  **描述外貌、性质、颜色**：「名词 + を + している」
    *   彼女は可愛い顔をしている。
    *   私は1987年に生まれている。
6.  **经历、经验**
    *   私は3年前にも同じ病気をしている。
    *   王さんは大学時代日本に留学している。

***

## (二) Vてある

*   **接续：** (助词 **が**) + 他动词 + 「てある」
*   **含义：**
    1.  **表示人为作用下的结果状态存续。**
        *   壁にいろいろなポスターが貼ってある。
        *   ドアが開けてあります。
    2.  **(延伸用法) 表示事先已经把某事做好了。** (注意：描述当下的状态一般不用过去式)
        *   そのことは山田さんに伝えてあります。
        *   試験に必要なことは全部教えてあります。
    *
        > **注意：** 如果描述过去某个具体时间点，人为发生的结果状态存续，才使用过去式。
        >
        > *   例：昨日、その部屋に入ったら、窓が開けてあった。

***

## (三) Vておく (とく)

*   **接续：** 动词 + 「ておく」
*   **含义：**
    1.  **事先去做。** (Vておきます、Vておく)
        *   お客さんが来る前に、部屋を掃除しておきます。
        *   山田さんに来るかどうか聞いておいてください。
    2.  **事先做好 (放任不管/保持原状)。** (Vておきました、Vておいた)
        *   そろそろ暗くなるから、電気をつけておきました。
        *   お客さんが来ないから、コップを元の場所に戻しておいた。

### 【辨析总结：ている vs てある vs ておく】

| 词形      | 核心含义                                                              | 备注               |
| :------ | :---------------------------------------------------------------- | :--------------- |
| **ている** | ①正在进行 <br> ②结果状态的存续 <br> ③习惯/身份/外貌/经历                             | **侧重对现象状态的描述**   |
| **てある** | ①**人为作用下**的结果状态存续 <br> (助词 **が** + **他动词** + てある) <br> ②事先已经做好了某事 | **侧重人为完成后留下的状态** |
| **ておく** | ①事先去做某事 (非过去式) <br> ②事先做好某事 (过去式)                                 | 侧重准备动作           |

***

## (四) Vてみる (見る)

*   **用法：** 表示尝试做某事。
    *   もう一度先生と相談してみます。
    *   似合うかどうか、着てみてください。

> **补充：Vてみせる (見せる)**
>
> *   **用法：** 表示做某事的决心 (做给...看)。
>     *   今年どうしても試験にパスしてみせる。
>     *   今度の試合、絶対勝ってみせる。

***

## (五) Vてしまう (仕舞う) 「ちゃう」

1.  **单纯表示动作的结束、完成。** (现在/未来)
    *   この本をもう全部読んでしまいました。
    *   開けちゃおう。
2.  **表示该动作结束后所伴随的消极、遗憾的语气。** (更常用)
    *   大切な資料を忘れてしまいました。
    *   彼に騙されてしまって困っています。

> **补充：**
>
> *   与情感类的单词 (**泣く・笑う・感動する** 等) 搭配使用 **てしまう** 时，表示该情感难以抑制，**自然流露出来**。

***

## (六) Vていく・てくる

### 1. ていく「行く」“去”

1.  **表示以说话人为起点，动作由近及远。**
    *   鳥が山の方へ飛んでいきました。
    *   李さんはあちらへ歩いていきます。
2.  **表示从现在到将来的发展变化过程及趋势。** (现在 -> 未来)
    *   これから寒くなっていきます。
    *   田舎の人口は だんだん 減っていくでしょう。
3.  **表示原来存在的事物消失不见。** (消失)
    *   だんだん雪が溶けていきます。
    *   每日、多くの人が交通事故で死んでいきます。
4.  **表示在某地做完某事之后，再到别的地方去。** (“做完再去”)
    *   日本に行く前に、日本語を勉強していきます。
    *   病院へ行く途中で、お見舞いの花を買っていきましょう。

### 2. てくる「来る」“来”

1.  **表示以说话人为起点，动作由远及近。**
    *   李さんは私に向かって走ってきました。
    *   遠くから音楽が伝わってきました。
2.  **表示由过去到现在某种状态的变化过程和趋势。** (过去 -> 现在)
    *   私は 子供の時から 日本語を勉強してきました。
    *   最近、日本に留学する人が 増えてきました。
3.  **某种状态开始或出现。** (常用于信息、气味、声音的到来)
    *   雪が降ってきました。
    *   ずっと読んでいたので、目が疲れてきました。
4.  **表示循环性动作。** (“去了又来”)
    *   ちょっと手紙を出してきます。
    *   タバコを買いに行ってきます。

### 【对比总结：ていく vs てくる】

| 比较项目            | ていく「行く」(てく)     | てくる「来る」                 |
| :-------------- | :-------------- | :---------------------- |
| **1. 距离感**      | 由**近**及**远**    | 由**远**及**近**            |
| **2. (距离感) 延伸** | 消失              | 出现                      |
| **3. 时间段**      | **现在** 到 **未来** | **过去** 到 **现在** (要用过去式) |
| **4. 动作顺序**     | 做完再去            | 去了又来                    |

## (七) 还原练习与做题方法

### 还原练习 (尝试还原以下变形)

### 还原练习答案

| 变形 (题目)   | 原形 (字典形) | 语法 / 备注                                                     |
| :-------- | :------- | :---------------------------------------------------------- |
| **ています**  | **ている**  | `Vている` 的 `ます` 形（敬体）。表示正在进行或状态存续。                            |
| **ていきます** | **ていく**  | `Vていく` 的 `ます` 形（敬体）。表示由近及远、消失或将来。                           |
| **ておって**  | **ておる**  | `Vておる` 的 `て` 形。`ておる` 是 `ている` 的自谦语或郑重语。                      |
| **ておいて**  | **ておく**  | `Vておく` 的 `て` 形。表示事先准备或放任不管。                                 |
| **ております** | **ておる**  | `Vておる` 的 `ます` 形。`ている` 的自谦语（如：私は〜を知っております）。                  |
| **ておきます** | **ておく**  | `Vておく` 的 `ます` 形（敬体）。                                        |
| **ていって**  | **ていく**  | `Vていく` 的 `て` 形。注意：`行く` 的て形是促音变 `行って`。                       |
| **ていて**   | **ている**  | `Vている` 的 `て` 形。也就是 `て+いる` 的 `て` 形变形（いる `$\rightarrow$` いて）。 |
| **てこない**  | **てくる**  | `Vてくる` 的 `ない` 形（否定）。`くる` `$\rightarrow$` `こない`。             |
| **てきて**   | **てくる**  | `Vてくる` 的 `て` 形。`くる` `$\rightarrow$` `きて`。                   |
| **といて**   | **ておく**  | **口语缩略形式**。`ておいて` `$\rightarrow$` `といて`（把 `eo` 音缩读为 `o`）。   |
| **ちゃった**  | **てしまう** | **口语缩略形式**。`てしまった` `$\rightarrow$` `ちゃった`（表示遗憾或彻底完成）。       |

### 做题方法

1.  **考虑题目里的助词、接续** (特别是 ている・てある 的区别)
2.  **注意还原、用法** (判断是哪个辅助动词)
3.  **ていく・てくる 具有对立性** (通过时间方向、空间方向判断)
