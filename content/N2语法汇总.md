## 限定・范围・唯一

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| ～に限（かぎ）り | N + に限り | 只限于 | 公告、通知、优惠条件 | 强调适用对象被限定 |
| ～に限（かぎ）って | N + に限って | 偏偏、唯独 | 常带意外、不满、反常 | 也可表示“唯独某人不可能” |
| ～に限（かぎ）らず | N + に限らず | 不限于、不只 | 扩大范围 | 后面常接“也……” |
| ～に限（かぎ）る | V辞書形 / Vない形 / N + に限る | 最好是、只有……最好 | 主观推荐、经验判断 | 和「ことだ」都能给建议，但更像“最佳选择” |
| ～とは限（かぎ）らない | 普通形 + とは限らない | 未必、不一定 | 否定绝对判断 | 常用于打破一般印象 |
| ～限（かぎ）り | V辞書形 / Vない形 / Vている / Nの + 限り | 只要……就、在……范围内 | 条件、范围、能力极限 | 不是所有「限り」都等于限定 |
| ～限（かぎ）りでは | 見る / 聞く / 知る 等 + 限りでは | 就……范围来看 | 信息来源有限 | 常用于谨慎判断 |
| ～を限（かぎ）りに | N + を限りに | 以……为最后 | 截止、终止 | 多用于时间点 |

### 辨析重点

- `に限り` 是客观限制对象；`に限って` 常带“偏偏在这种时候”或“唯独这个人不会”的语气。
- `に限る` 是说话人认为最优；`とは限らない` 是否定“必然如此”。
- `限り` 既可以表示条件，也可以表示范围和极限，整理时不要只归到“限定”。

### 代表例句

> **クーポンを持っているお客様に限り、半額になります。**  
> 只限持有优惠券的客人半价。

> **急いでいる時に限って、渋滞しています。**  
> 偏偏赶时间的时候堵车。

> **私の知っている限りでは、まだ独身のはずだ。**  
> 就我所知，他应该还单身。

## 并行・逆接：ながら / つつ

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| ～ながら | Vます形去ます + ながら | 一边……一边…… | 日常、自然 | 前后动作同一主体 |
| ～ながら（も） | Vます形去ます / A / N + ながら（も） | 虽然……但是…… | 书面或固定表达也多 | 可接形容词、名词 |
| ～つつ | Vます形去ます + つつ | 一边……一边…… | 书面、生硬 | 基本只接动词 |
| ～つつ（も） | Vます形去ます + つつ（も） | 明知……却…… | 书面、反省语气 | 和逆接的「ながらも」接近 |
| ～つつある | Vます形去ます + つつある | 正在逐渐…… | 变化进行中 | 不表示“一边……一边……” |

### 辨析重点

- `ながら` 更口语、更常用；`つつ` 更书面。
- `ながらも` 能接形容词和名词；`つつも` 基本接动词。
- `つつある` 单独记为“变化正在推进”，不要和并行动作混在一起。

### 代表例句

> **音楽を聴きながら勉強する。**  
> 一边听音乐一边学习。

> **体に悪いと知っていながら、タバコをやめられない。**  
> 明知对身体不好，却戒不了烟。

> **日本で子供の数がだんだん減（へ）りつつあります。**  
> 日本儿童数量正在逐渐减少。

## 原因・理由

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| ～ため / ～ために | 普通形 / Aな / Nの + ため（に） | 因为、由于 | 客观、书面 | 也可表示目的，靠前后文判断 |
| ～につき | N + につき | 因……；每…… | 公告、通知、正式 | 原因义常见于告示 |
| ～もので / ～ものですから | 普通形 / Aな / Nな + もので | 因为……所以…… | 礼貌解释、辩解 | 常用于道歉理由 |
| ～せいで / せいか | 普通形 / Aな / Nの + せいで | 都怪……、也许因为…… | 多为坏结果 | `せいか` 表不确定原因 |
| ～おかげで / おかげだ | 普通形 / Aな / Nの + おかげで | 多亏…… | 多为好结果 | 有时反讽 |
| ～ことから / ところから | 普通形 + ことから / ところから | 由……得出原因或判断 | 说明由来、根据 | 比普通「から」更书面 |
| ～ばこそ | 普通形 + ばこそ | 正因为……才…… | 强调真正原因 | 常用于强烈说明 |
| ～からこそ | 普通形 + からこそ | 正因为…… | 强调原因 | N3 基础，语气直接 |
| ～にほかならない | N + にほかならない / ためにほかならない | 正是……、无非就是…… | 强判断 | 用来锁定原因或本质 |

### 辨析重点

- `ため` 客观，`もので` 用于解释或道歉，`せいで` 偏坏结果，`おかげで` 偏好结果。
- `につき` 的原因用法很正式，常出现在“故障中につき、立入禁止”等告示。
- `ことから` 更像“从这个事实可知”；`ばこそ / からこそ` 更像“正因为如此”。

### 代表例句

> **外国人観光客が増えたため、外国語のパンフレットを作ることになった。**  
> 因为外国游客增加，所以决定制作外语手册。

> **店内改装中につき、今月は臨時休業いたします。**  
> 因店内装修，本月临时停业。

> **みんなが手伝ってくれたおかげで、引っ越しが早く済んだ。**  
> 多亏大家帮忙，搬家很快完成了。

## 逆接・让步

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| ～ても / でも | 普通形て形 + も | 即使……也…… | 基础让步 | 范围广 |
| たとえ～ても | たとえ + ても | 即使……也…… | 强调假设 | `たとえ` 强化让步 |
| ～としても | 普通形 + としても | 即使假设……也…… | 假设条件 | 和身份的「として」不同 |
| ～にしても / にしろ / にせよ | 普通形 / N + にしても 等 | 即使……；无论…… | 让步、列举 | 可单用或成对使用 |
| ～にもかかわらず | 普通形 / N + にもかかわらず | 尽管……却…… | 书面、反预期 | 后项多为意外结果 |
| ～ながらも | Vます形去ます / A / N + ながらも | 虽然……但是…… | 书面或固定表达 | 可接范围比 `つつも` 宽 |
| ～つつも | Vます形去ます + つつも | 明知……却…… | 书面、心理矛盾 | 常接「知りつつも」「思いつつも」 |
| ～わりに | 普通形 / Aな / Nの + わりに | 虽然按理……却…… | 与预期不符 | 常含评价 |
| ～にしては | N / 普通形 + にしては | 就……而言算是…… | 按身份、标准评价 | 标准来自前项 |
| ～くせに | 普通形 / Aな / Nの + くせに | 明明……却…… | 责备、不满 | 语气比「のに」强 |
| ～反面 | 普通形 / Aな / Nである + 反面 | 另一方面 | 对比同一事物两面 | 不一定是转折责备 |
| ～どころか | 普通形 / N + どころか | 别说……甚至…… | 强烈反差 | 后项更出乎意料 |

### 辨析重点

- `ても` 是基础让步；`たとえ〜ても` 更强调“就算真的发生”。
- `にもかかわらず` 更书面，适合写作；`くせに` 带责备。
- `にしては` 的评价标准是前项身份；`わりに` 是“按理说应该……但实际……”。

### 代表例句

> **たとえ反対されても、自分の考えは変えません。**  
> 即使被反对，也不会改变自己的想法。

> **貧しいながらも、幸せに暮らしているそうです。**  
> 听说虽然贫穷，但生活得很幸福。

> **飛行機で向かったのに、早く着くどころか二時間も遅れた。**  
> 明明坐飞机去，别说早到，反而晚了两个小时。

## 根据・手段・来源：による系列

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| ～によって | N + によって | 根据、通过、由于、由…… | 多义核心项 | 必须按后项判断意思 |
| ～により | N + により | 由于、根据 | 更正式 | 常作书面中顿 |
| ～による + N | N + による + N | 由……导致的、根据……的 | 修饰名词 | 连体形 |
| ～によっては | N + によっては | 根据……不同，有时…… | 个别情况 | 后面常说特殊结果 |
| ～によると / によれば | N + によると / によれば | 据……所说、根据…… | 引用来源 | 后面常接传闻、推量 |
| ～を通（つう）じて / 通（とお）して | N + を通じて / 通して | 通过、经由；整个期间 | 手段或期间 | `通じて` 更书面 |
| ～に基（もと）づいて | N + に基づいて | 基于…… | 依据明确 | 多接规则、数据、经验 |
| ～に沿（そ）って | N + に沿って | 沿着、按照 | 路线、方针 | 比「基づいて」更像遵循路线 |
| ～に応（おう）じて | N + に応じて | 根据、响应 | 按变化调整 | `に応えて` 偏回应期待 |

### 辨析重点

- `によって` 可表示手段、原因、依据、动作主体、差异，先看后项动词和语境。
- `によると / によれば` 只管“信息来源”，不表示原因。
- `に基づいて` 是依据；`に沿って` 是按照路线或方针；`に応じて` 是随对象变化而调整。

### 代表例句

> **成績によって順位をつける。**  
> 根据成绩排名。

> **天気予報によると、明日は雨が降るということだ。**  
> 据天气预报说明天会下雨。

> **法律に基づいて判断する。**  
> 基于法律判断。

## 关于・对象・立场

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| ～について | N + について | 关于、就…… | 普通、范围广 | 主题内容 |
| ～についての | N + についての + N | 关于……的 | 修饰名词 | 连体形式 |
| ～に関（かん）して | N + に関して | 关于、与……有关 | 更正式 | 比「について」更书面 |
| ～に関する | N + に関する + N | 关于……的 | 书面修饰名词 | 常用于标题、文件 |
| ～に対（たい）して | N + に対して | 对于……；与……相对 | 对象、态度、对比 | 可表示动作对象或对比 |
| ～にとって | N + にとって | 对……来说 | 评价立场 | 不表示直接动作对象 |
| ～において | N + において | 在……、于…… | 场所、领域、时代 | 书面，类似「で」但正式 |
| ～における | N + における + N | 在……中的 | 修饰名词 | 连体形式 |

### 辨析重点

- `について` 是普通“关于”；`に関して` 更正式。
- `に対して` 有明确对象或对比；`にとって` 是站在某人或某群体立场评价。
- `において` 表示场所、领域、时代，不等于“关于”。

### 代表例句

> **大学では日本文学史について研究したいと思っています。**  
> 想在大学研究日本文学史。

> **先日の会議では、彼の説明に対して質問が集中した。**  
> 前几天的会议上，大家的问题集中在他的说明上。

> **だれにとってもいちばん大切なものは健康だと思います。**  
> 我觉得对任何人来说最重要的都是健康。

## 推量・当然・结论：はず / わけ

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| ～はずだ | 普通形 / Aな / Nの + はずだ | 按理应该…… | 基于事实推测 | 是逻辑推测，不是义务 |
| ～はずがない | 普通形 + はずがない | 不可能…… | 强烈否定 | 比「ないはずだ」更强 |
| ～わけだ | 普通形 / Aな / Nな・の + わけだ | 也就是说、怪不得 | 解释结论 | 根据前文得出结论 |
| ～というわけだ | 普通形 + というわけだ | 也就是说…… | 归纳说明 | 更容易直接接句子 |
| ～わけではない | 普通形 + わけではない | 并不是…… | 部分否定 | 否定整体判断 |
| ～わけがない | 普通形 + わけがない | 不可能…… | 强否定 | 接近「はずがない」 |
| ～わけにはいかない | V辞書形 + わけにはいかない | 不能…… | 社会常识、责任 | 不是能力不能 |
| ～ないわけにはいかない | Vない形 + わけにはいかない | 不能不…… | 不得不做 | 双重否定 |

### 辨析重点

- `はずだ` 是“照理说应该”；`べきだ` 是“应该这么做”。
- `わけだ` 是根据前文得出的理解；`はずだ` 是基于信息做推测。
- `わけではない` 是部分否定，常用于“并不是完全不……”。

### 代表例句

> **昨日速達で出しましたから、遅くても明日には着くはずです。**  
> 昨天用速递寄出，所以最迟明天应该会到。

> **つまり、一ヶ月で7kg痩せたわけだ。**  
> 也就是说，一个月瘦了 7 公斤。

> **今日は試験があるので、学校を休むわけにはいかない。**  
> 今天有考试，不能请假不去学校。

## 义务・建议・最好

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| ～べきだ / べきではない | V辞書形 + べきだ | 应该、不应该 | 道理、常识、道德 | `する` 可用 `すべき` |
| ～ことだ | V辞書形 / Vない形 + ことだ | 最好……、应该…… | 个人建议、忠告 | 比「べき」更像给建议 |
| ～に限（かぎ）る | V辞書形 / Vない形 / N + に限る | 最好是…… | 主观最佳选择 | 经验感强 |
| ～ものだ / ものではない | 普通形 + ものだ / ものではない | 理应……、不该…… | 常识、社会规范 | 更像一般道理 |
| ～なければならない / なくてはいけない | Vない形 + なければならない 等 | 必须…… | 规则、义务 | N3 基础义务 |
| ～ざるを得（え）ない | Vない形去ない + ざるを得ない | 不得不…… | 客观上没办法 | `する` 为 `せざるを得ない` |
| ～しかない | V辞書形 + しかない | 只好…… | 没别的办法 | 比「ざるを得ない」更口语 |

### 辨析重点

- `べき` 是道理上应该；`なければならない` 是规则或义务上必须。
- `ことだ` 常用于建议别人；`に限る` 是“这种情况最佳选择”。
- `ざるを得ない` 和 `しかない` 都是没办法，前者更书面。

### 代表例句

> **約束は守るべきです。**  
> 约定应该遵守。

> **痩せたかったら、間食をやめることだ。**  
> 如果想瘦，最好停止吃零食。

> **疲れている時は早く寝るに限るよ。**  
> 累的时候最好早点睡。

## 变化・趋势・伴随

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| ～にしたがって | V辞書形 / N + にしたがって | 随着…… | 前后同步变化 | 常接自然变化 |
| ～につれて | V辞書形 / N + につれて | 随着…… | 变化联动 | 和「にしたがって」接近 |
| ～にともなって | V辞書形 / N + にともなって | 伴随…… | 书面、规模较大 | 强调同时发生的变化 |
| ～とともに | V辞書形 / N + とともに | 随着；同时；和……一起 | 多义 | 可表示共同动作 |
| ～一方（いっぽう）だ | V辞書形 + 一方だ | 一直……、越来越…… | 多为单向变化 | 常用于消极变化，也可积极 |
| ～つつある | Vます形去ます + つつある | 正在逐渐…… | 书面 | 聚焦变化过程 |
| ～ていく | Vて + いく | 逐渐向未来变化、远离 | 方向、趋势 | 和「てくる」方向相反 |
| ～てくる | Vて + くる | 到现在为止变化、靠近、出现 | 时间或空间靠近 | 也可表示变化出现 |
| ～ようになる | V辞書形 / V可能形 + ようになる | 变得会…… | 能力、习惯变化 | 变化结果 |

### 辨析重点

- `にしたがって / につれて` 是典型“随着 A，B 也变化”。
- `にともなって` 更书面，常用于社会、制度、规模性变化。
- `一方だ` 表示单向发展；`つつある` 表示变化正在进行。

### 代表例句

> **年を取るにつれて、体力が落ちてきた。**  
> 随着年龄增长，体力下降了。

> **人口が少しずつ減りつつあります。**  
> 人口正在一点点减少。

> **生活は苦しくなる一方だ。**  
> 生活越来越艰难。

| ～がきっかけで | N + がきっかけで | 因……成为契机 | 因果说明 | 比「をきっかけに」更说明原因 |
| ～をはじめ（として） | N + をはじめとして | 以……为代表 | 列举代表 | 后接同类群体 |

|---|---|---|---|---|
| ～という | 普通形 + という + N | 叫作……的、内容是……的 | 说明内容 | 后接信息类名词 |

## 判断来源・视点

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| ～から言（い）うと / 言えば / 言って | N + から言うと | 从……来说 | 评价角度 | 多接立场、观点 |
| ～から見（み）ると / 見れば / 見て | N + から見ると | 从……来看 | 观察判断 | 更偏外部观察 |
| ～からすると / すれば | N + からすると | 从……来看、根据……判断 | 判断依据 | 可接人或事实 |
| ～からして | N + からして | 单从……来看就…… | 举代表性依据 | 常带“连……都”感 |
| ～にかけては | N + にかけては | 在……方面 | 擅长领域 | 常接评价最高 |
| ～上（じょう） | N + 上 | 在……上、从……方面 | 固定搭配 | 法律上、経済上 等 |

### 辨析重点

- `から言うと` 是从立场或观点说；`から見ると` 是从观察角度看。
- `からして` 常拿一个例子作为判断依据，带“光是这一点就……”。
- `にかけては` 常表示在某领域非常优秀或无人能比。

### 代表例句

> **私の経験から言うと、この方法が一番いい。**  
> 从我的经验来说，这个方法最好。

> **彼の表情からすると、何か知っているようだ。**  
> 从他的表情来看，他好像知道些什么。

> **料理にかけては、彼の右に出るものはいない。**  
> 在料理方面，没有人比得过他。

## 身份・资格・定位

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| ～として | N + として | 作为…… | 身份、资格 | 可接评价或职责 |
| ～としては | N + としては | 作为……来说 | 从身份评价 | 带评价标准 |
| ～としても | N / 普通形 + としても | 即使作为……；即使假设…… | 身份或让步 | 看前项是否为身份 |
| ～を…として | NをNとして | 把……作为…… | 定位、用途 | 和「にして」相近 |
| ～を…にして | NをNにして | 把……变成/当作…… | 结果、状态 | 更强调变化结果 |
| ～にほかならない | N + にほかならない | 正是…… | 强判断 | 锁定本质 |
| ～にすぎない | N / 普通形 + にすぎない | 只不过…… | 降低评价 | 带“不过如此” |
| ～ものか / もんか | 普通形 + ものか | 怎么可能……、绝不…… | 强烈否定 | 口语可作「もんか」 |

### 辨析重点

- `として` 是身份资格；`としても` 也可进入假设让步，要看句意。
- `にほかならない` 强调“正是”；`にすぎない` 强调“只不过”。
- `ものか` 是反问式强否定，语气很强。

### 代表例句

> **彼は医者として働いている。**  
> 他作为医生工作。

> **それは努力の結果にほかならない。**  
> 那正是努力的结果。

> **これは一つの例にすぎない。**  
> 这只不过是一个例子。

## 敬语・授受・许可

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| お / ご～いただく | お / ご + Vます形去ます + いただく | 承蒙对方为我做 | 自谦、商务 | 主语多为自己一方 |
| お / ご～くださる | お / ご + Vます形去ます + くださる | 对方为我做 | 尊他 | 主语是对方 |
| お / ご～です | お / ご + Vます形去ます + です | 您正在…… | 尊他 | 接续限制较多 |
| ～ていらっしゃる | Vて + いらっしゃる | 您正在…… | 尊他 | 「いる」尊敬语 |
| ～させていただく | 使役て形 + いただく | 请允许我…… | 自谦、正式 | 不要滥用 |
| ～させてもらう | 使役て形 + もらう | 获得许可做…… | 口语一些 | 恩惠来自对方许可 |
| ～てもらってもいいですか | Vて + もらってもいいですか | 能麻烦您……吗 | 请求 | 礼貌请求 |
| ～ように言（い）う | V辞書形 / Vない形 + ように言う | 转达要求 | 间接命令 | 后项是传达指示 |

### 辨析重点

- `いただく` 是自己承蒙对方；`くださる` 是尊敬对方为我做。
- `させていただく` 是“请允许我做”，不是普通礼貌万能句。
- 请求别人做事时，`てもらってもいいですか` 比直接命令柔和。

### 代表例句

> **資料をご確認いただけますか。**  
> 能请您确认资料吗？

> **先生が説明してくださいました。**  
> 老师为我说明了。

> **発表を始めさせていただきます。**  
> 请允许我开始发表。

## 使役・被动・受害

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| ～せる / させる | 使役形 | 让……做 | 指示、允许、导致 | 自动词/他动词句型不同 |
| ～させられる | 使役被动 | 被迫做…… | 不情愿 | 常带受害感 |
| ～られる | 被动形 | 被…… | 被动 | 也可能是可能、尊敬 |
| ～られてしまう | 被动て + しまう | 不幸被…… | 受害、遗憾 | 强化负面结果 |
| ～てもらう / いただく | Vて + もらう | 请别人为我做 | 受益 | 和被动视角不同 |
| ～てくれる / くださる | Vて + くれる | 别人为我做 | 受益 | 主语是别人 |
| ～てあげる / さしあげる / やる | Vて + あげる | 为别人做 | 给予恩惠 | 注意对象和礼貌 |

### 辨析重点

- `させられる` 是“被迫”；普通被动只是“被……”。
- `られる` 可能是被动、可能、尊敬，要靠句意判断。
- 授受表达强调恩惠方向，不只是动作发生。

### 代表例句

> **子どものとき、父に掃除をさせられた。**  
> 小时候被父亲逼着打扫。

> **雨に降られて、服が濡れた。**  
> 被雨淋了，衣服湿了。

> **友達が引っ越しを手伝ってくれた。**  
> 朋友帮我搬家。

## 动作处理・状态保持

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| ～ておく | Vて + おく | 事先做、保持 | 准备、放置 | 口语常缩成「とく」 |
| ～させておく | 使役て形 + おく | 让……保持、放任 | 管理或放任 | 主体让他人处于状态 |
| ～てある | Vて + ある | 已经做好并保持 | 结果状态 | 多接他动词 |
| ～まま | Vた形 / Vない形 / Nの + まま | 保持原样 | 状态不变 | 常表示未处理 |
| ～っぱなし | Vます形去ます + っぱなし | 一直……不管 | 放置、负面 | 常含责备 |
| ～て済（す）む | Vて + 済む | ……就解决 | 不必更多 | `ないで済む` 表免于 |
| ～ないで済む / ずに済む | Vない形 + で済む | 不用……也行 | 避免、免除 | 结果较轻 |
| ～きる | Vます形去ます + きる | 做完、彻底…… | 完成到极限 | 否定是做不完 |
| ～ぬく | Vます形去ます + ぬく | 坚持到最后 | 过程艰难但完成 | 比「きる」更强调坚持 |
| ～直（なお）す | Vます形去ます + 直す | 重新…… | 修正、重做 | N3 常见 |

### 辨析重点

- `てある` 表人为准备后的状态；`ている` 只是状态或进行。
- `まま / っぱなし` 都有“放着不管”可能，`っぱなし` 负面更强。
- `きる` 强调完成或极限；`ぬく` 强调克服困难坚持到底。

### 代表例句

> **窓が開けてある。**  
> 窗户已经被打开着。

> **電気をつけっぱなしで寝てしまった。**  
> 灯开着没关就睡着了。

> **最後まで走り抜いた。**  
> 坚持跑到了最后。

## 否定・省略・无视

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| ～ことなく | V辞書形 + ことなく | 不……而…… | 书面 | 接近「ないで」 |
| ～ずに / ず | Vない形去ない + ずに | 不……而…… | 书面或固定 | `する` 为 `せず` |
| ～ぬ / ん | Vない形去ない + ぬ / ん | 不…… | 古风、书面、口语缩略 | `わからん` 等 |
| ～を問（と）わず | N + を問わず | 不论…… | 书面 | 不受条件影响 |
| ～にかかわらず | N / 普通形 + にかかわらず | 不管…… | 书面 | 和「にもかかわらず」不同 |
| ～もかまわず | N + もかまわず | 不顾…… | 批评、不在意 | 强调忽视应顾及的事 |
| ～ぬきで / ぬきに | N + ぬきで | 省去、不含 | 排除 | 可表示“不谈……” |
| ～どころではない | V辞書形 / N + どころではない | 根本不是……的时候 | 没余裕 | 表示无法顾及 |
| ～てはいられない | Vて + はいられない | 不能一直…… | 没时间、不能拖 | 紧迫感 |
| ～ないことはない | Vない形 + ことはない | 也不是不…… | 双重否定 | 表示可能但不积极 |

### 辨析重点

- `にかかわらず` 是“不管”；`にもかかわらず` 是“尽管却”。
- `を問わず` 常接年龄、性别、经验等条件。
- `ことなく / ずに` 都是不做前项而做后项，前者更书面。

### 代表例句

> **経験を問わず、アルバイトを募集しています。**  
> 不限经验，招聘兼职。

> **雨にもかかわらず、試合は行われた。**  
> 尽管下雨，比赛仍举行了。

> **彼は周囲の反対もかまわず、計画を進めた。**  
> 他不顾周围反对，推进了计划。

## 决心・尝试・愿望

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| ～ようとする | 意向形 + とする | 正要……、尝试…… | 动作即将开始或努力 | 可表示“不愿意” |
| ～ようと思（おも）う | 意向形 + と思う | 打算…… | 个人意志 | N3 常见 |
| ～ようか～まいか | 意向形 + か + まいか | 要不要…… | 犹豫 | 书面感 |
| ～ようが～まいが | 意向形 + が + まいが | 无论是否…… | 让步 | 和「ようと〜まいと」接近 |
| ～まい | V辞書形 / するまい | 绝不……、不会吧 | 否定意志或推量 | `する` 可为 `すまい` |
| ～ものなら | V可能形 + ものなら | 如果能……的话 | 实现困难的愿望 | 也可用于挑衅 |
| ～たいものだ | Vます形去ます + たいものだ | 真想…… | 愿望、感叹 | 不同于理由的「ものだ」 |
| ～ばと思います | Vば + と思います | 希望能…… | 委婉愿望 | 礼貌表达 |
| ～つもり | V辞書形 / Vた形 + つもり | 打算；自以为 | 意图或主观认定 | `たつもり` 可表“就当作” |
| ～ことにする / ことになる | V辞書形 / Vない形 + ことにする / なる | 决定…… / 被决定…… | 主观决定或外部决定 | 主体不同 |

### 辨析重点

- `ようとする` 是正要做或努力尝试；`ようと思う` 是打算。
- `まい` 可以是否定意志，也可以是否定推量。
- `ことにする` 是自己决定；`ことになる` 是结果或外部决定。

### 代表例句

> **出かけようとした時、電話が鳴った。**  
> 正要出门时，电话响了。

> **休めるものなら、一週間くらい休みたい。**  
> 如果能休息的话，真想休一周左右。

> **旅行に行こうか行くまいか、まだ迷っている。**  
> 还在犹豫要不要去旅行。

## 高频单点补充

### 速查总表

| 表达 | 接续 | 核心意思 | 语感/场景 | 易混点 |
|---|---|---|---|---|
| ～ばかり | N / Vている + ばかり | 光是、净是；大约；刚刚 | 多义 | 看接续和后项 |
| ～ばかりだ | V辞書形 + ばかりだ | 越来越…… | 单向变化 | 接近「一方だ」 |
| ～だけに / だけあって | 普通形 / N + だけに | 正因为、不愧是 | 符合期待 | `だけに` 也可表更加 |
| ～かわりに | 普通形 / Nの + かわりに | 代替；虽……但……；交换 | 多义 | 看前后是否代偿 |
| ～次第（しだい）で | N + 次第で | 取决于…… | 条件变化 | 后项随前项决定 |
| ～次第だ | 普通形 + 次第だ | 原因经过是…… | 说明来龙去脉 | 常用于正式说明 |
| ～たて | Vます形去ます + たて | 刚刚…… | 新鲜状态 | 常接食物、完成物 |
| ～かけ | Vます形去ます + かけ | 做到一半、刚开始 | 未完成 | `食べかけ` 等 |
| ～ぶり | 时间N + ぶり | 时隔…… | 久违 | `久しぶり` |
| ～向（む）け | N + 向け | 面向…… | 目标对象 | 商品、文章、服务 |
| ～向（む）き | N + 向き | 适合…… | 性质适配 | 比「向け」更偏适合 |
| ～を込（こ）めて | N + を込めて | 满怀……、带着…… | 感情、心意 | 常接心、愛情、願い |

### 辨析重点

- `ばかり` 多义，最容易靠接续和后项判断；`ばかりだ` 是趋势。
- `向け` 是面向某对象制作；`向き` 是性质上适合某对象。
- `次第で` 表取决于条件；`次第だ` 表说明事情经过。

### 代表例句

> **この雑誌は若い女性向けです。**  
> 这本杂志面向年轻女性。

> **結果は努力次第で変わる。**  
> 结果取决于努力。

> **愛情を込めて、お弁当を作った。**  
> 带着爱意做了便当。
